# Upstream v1.1.0 Sync Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Finish the OpenClaw adaptation of `mattpocock/skills` v1.1.0 and promote the validated skill set to both OpenClaw profiles.

**Architecture:** Keep the Codex app-server default equal to the upstream plugin manifest and keep the OpenClaw-global default restricted to `grill-me` and `handoff`. Derive validation expectations from the manifest and lock file so future upstream additions do not require duplicated hard-coded lists.

**Tech Stack:** Bash, Node.js test runner, GitHub Actions, OpenClaw profile skill directories.

## Global Constraints

- The upstream release is exactly `v1.1.0` at `d574778f94cf620fcc8ce741584093bc650a61d3`.
- Codex app-server installs every skill in `.claude-plugin/plugin.json`.
- OpenClaw-global installs only `grill-me` and `handoff` by default.
- Deprecated, in-progress, personal, and misc skills remain excluded by default.
- Promote Soulmate before main Sage; archive removed live skill directories before deletion.
